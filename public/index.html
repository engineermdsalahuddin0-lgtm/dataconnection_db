    Cash slips

    Actual gross = OrgGross × ratio. Joined before cut-off: actual gross ≥ 60,000; joined on/after: actual gross ≥ 100,000. Ratio: employee → designation → 1.0. Bank = OrgGross, cash = actual gross − OrgGross.

    #CodeNameDesignationDOJOrgGrossRatioSourceActual grossBankCash

    Click a row to see its full calculation. The trace is only shown here, never on the printed slip.

    Cash slips by manual mapping

    Pick the salary table and the employee table, then tell the app which column holds each field. Columns with matching names are picked automatically; fields still marked needs a column must be chosen by hand. If a field (for example Designation) lives in another table, use + Add table to join it.

    Cash slips from a custom query

    Replace the table / column names in the template with yours, or paste your own SELECT query. Only SELECT is allowed (read-only). The result must contain these column names (rename with AS if needed): EmployeeCode, EmployeeName, Designation, OrgGross, OrgBasic, OrgHouseRent, OrgMedical, OrgConvence, DOJ, DOS.

    Ctrl+Enter = Run. Order: anyone with a DOS is excluded → actual gross (OrgGross × ratio) ≥ 60,000 / 100,000 depending on DOJ → bank = OrgGross, cash = actual − OrgGross. Only eligible employees appear in the table. Max 5,000 rows.
